# Sk/Ai Browser

Самостоятельный Windows-браузер с правой ИИ-панелью. Это отдельный продукт от Sk/Ai Agent.

## Состояние

Сделан только HTML/CSS/JS UI-spike. Он не содержит браузерного движка, сетевого доступа, ИИ-поставщика, профиля, cookie-хранилища, голосовой записи или установщика.

Открой `src/index.html` в обычном браузере, чтобы посмотреть компоновку. Реальный движок и стратегия обновлений остаются открытым решением до spike.
