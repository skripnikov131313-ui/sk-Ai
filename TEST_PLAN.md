# План проверок

## UI spike

- Разметка сохраняет иерархию «вкладки / навигация / сайт слева / AI справа».
- Открытие панели анимирует физическое перемещение Ai из-за `/` и не теряет диалог.
- Светлая/тёмная темы переключаются; ширина панели регулируется.
- При `prefers-reduced-motion` animation отключается.
- Мобильная ширина и клавиатурная навигация остаются работоспособными.
- UI не обращается к сети, микрофону или системным API.

## Native Browser

После выбора движка проверить воспроизводимую сборку, обновление движка, изоляцию процессов, HTTPS/permissions/downloads, память/CPU на 1/5/10 вкладках, offline-поведение локальной модели, prompt injection, DPAPI-secret storage, доступность, клавиатуру и screen reader.
