# Начальная архитектура

Решение по движку не принято; сначала технический spike. Рассматриваются WebView2 Evergreen и CEF. Веб-движок, UI Shell, Provider Adapters, Local Model Manager, Voice, AI Security, Browser Tool Gateway, Profiles/Secrets и Updates должны быть отдельными модулями.

Внешний контент неизменно недоверенный. Веб-страница не должна менять полномочия ИИ. Любое управление браузером идёт через ограниченные схемы инструментов, чувствительные операции требуют подтверждения.

Папка `src/prototype` демонстрирует только локальную компоновку и реакции UI. У неё нет API-интерфейса к будущему движку.
