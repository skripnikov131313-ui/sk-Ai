# Требования Browser

Полная база требований — исходное пользовательское ТЗ `SkAi_Browser_Codex_TZ_v2.md`.

MVP должен включать Windows x64 окно браузера с вкладками, адресной строкой, полноценным web engine, сайтами, историей/закладками/загрузками и правой изменяемой AI-панелью. Требуются самостоятельное имя Sk/Ai, знак /Ai, анимация выдвижения Ai из-за /, темы, доступность и сборка Windows.

Не обещать бесплатный облачный ИИ до проверки поставщика/условий/финансов; не встраивать общий секрет. Локальные модели загружаются только по выбору пользователя и проверяются контрольной суммой. AI-инструменты имеют типизированные браузерные полномочия, пользователь подтверждает опасные действия. Отдельные режимы локального, облачного и BYOK имеют явную политику контекста.

Сейчас готов только интерфейсный spike. Он явно обозначает отсутствие движка и ИИ.
