# Безопасность

- Сайт — недоверенный источник инструкций.
- LLM не получает безусловные права на файловую систему или системные API.
- Не отправлять пароли, cookies, историю и полный текст страницы поставщикам облака автоматически.
- Хранить BYOK-secret через Windows-protected storage (DPAPI/Credential Manager), не писать его в логи и резервные копии открытым текстом.
- Базовая защита движка должна работать независимо от модели и сетевого доступа.
- Чувствительные действия (разрешения, удаление/очистка, передача данных, действия на сайтах) требуют явного подтверждения.
- В UI-spike нет сбора данных, микрофона, API или действий на сторонних сайтах.
